# 🏋️‍♂️ IronFit Gym - Landing Page de Alto Rendimiento

¡Bienvenido al repositorio de **IronFit Gym**! Este proyecto es una landing page de alto impacto diseñada para el sector del fitness y bienestar, combinando una estética industrial con una experiencia de usuario enfocada en la conversión.

---

## 🌟 Características del Proyecto
- **Identidad Visual Fuerte:** Uso de una paleta de colores "High-Contrast" (Negro, Rojo Intenso y Gris Industrial) para transmitir energía y fuerza.
- **Tipografía de Impacto:** Integración de `Bebas Neue` para títulos contundentes y `Roboto` para una lectura clara.
- **Secciones Dinámicas:** - **Hero Section:** Con efecto Parallax y fondos de alta calidad.
  - **Cards de Servicios:** Diseño interactivo con efectos de elevación (hover).
  - **Tabla de Precios:** Destacado visual para el plan recomendado para guiar la decisión del usuario.
  - **Formulario de Contacto:** Integración funcional con validación mediante JavaScript.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Marcado semántico y optimizado para SEO.
- **CSS3 Avanzado:** - **Variables CSS:** Uso de `:root` para una gestión eficiente de colores y estilos.
  - **Filtros y Gradientes:** Superposición de capas para mejorar la legibilidad del texto sobre imágenes.
  - **Responsive Design:** Adaptabilidad completa mediante Media Queries y `clamp()` para tipografía fluida.
- **JavaScript (Vanilla):** - Manejo de eventos de formulario (`preventDefault`).
  - Lógica de selección de planes mediante alertas interactivas.
- **Font Awesome:** Iconografía vectorial para los servicios.

---

## 🏔️ Detalles del Diseño
El diseño utiliza fondos con texturas de concreto y acción deportiva, logrando una atmósfera de "gimnasio premium". Se aplicaron efectos de desenfoque y gradientes radiales para mantener el enfoque en el contenido principal.
